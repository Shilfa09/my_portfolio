# Shilfa Catherine — Web Developer Portfolio

A responsive personal portfolio website handcrafted using pure semantic HTML5, modern CSS3, and Vanilla JavaScript (ES6+).

## 🚀 Key Highlights

- **Pure Frontend Architecture**: 100% client-side with zero external frameworks, build steps, or server dependencies.
- **Modern Responsive Design**: Fluid typography, CSS Grid, Flexbox, and mobile-first layouts.
- **Dynamic Theming**: Dark and light mode toggle with system preference detection and localStorage persistence.
- **Interactive UI**: Custom typing hero effect, animated progress indicators, project category filters, and accessible modals.
- **Direct Contact**: Seamless client-side validation and direct email delivery without requiring backend databases or third-party server infrastructure.
- **WCAG 2.1 Accessibility (A11y)**: Semantic landmark structure, accessible ARIA attributes, keyboard navigation, and high contrast ratios.

## 🛠️ Technologies Used

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3**: Custom properties (CSS variables), CSS Grid, Flexbox, media queries, micro-animations
- **Vanilla JavaScript**: ES6+ modules, IntersectionObserver API, DOM manipulation, LocalStorage API
