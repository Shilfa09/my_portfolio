Introduction

About Me

A Computer Science student focused on learning the core foundations of the web and crafting clean, usable digital experiences.

Hello! I'm Shilfa Catherine, an undergraduate Computer Science student with a passionate focus on frontend web development. I believe that understanding the core building blocks of the web—HTML, CSS, and modern JavaScript—is the most reliable way to become an effective, adaptable software developer.

Throughout my coursework and personal projects, I enjoy creating websites that look great, adapt smoothly across desktop and mobile screens, and are accessible to everyone. Rather than relying on heavy templates or complex frameworks, I focus on writing clear, readable code and understanding how the browser renders every element.

I am actively looking for internship opportunities and collaborative web projects where I can contribute my enthusiasm, apply modern web standards, and continue growing as a developer.

Core Web Standards

Writing semantic HTML5 markup, responsive layouts using CSS Grid and Flexbox, and modular ES6+ JavaScript with zero external frameworks.

Curious and persistent learner experimenting with browser Web APIs, state management in pure JavaScript, and clean coding best practices.
